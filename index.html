How I build

コードを書くのはAI。決めるのは自分。

  1. 01

    企画 — 話して要件を固める

    思いついたアイデアを、AIとのヒアリング形式で「誰の・どんな課題を・何で解くか」まで言語化します。営業で顧客の課題を聞くのと同じ要領です。

  2. 02

    実装 — AIに書かせ、判断は自分で

    Claude Code と Codex を使い分けて実装します。技術選定やデザインの判断基準を先に文書化しておき、AIの提案がブレないようにしています。

  3. 03

    レビュー — 別のAIに採点させる

    一緒に書いたAIにレビューさせると、自分の答案を自分で採点することになります。差分だけを渡した独立したAIにレビューさせ、指摘は理由付きで採否を決めます。

  4. 04

    公開 — 出して、使って、直す

    App Store・Google Play・Web へ公開し、実際に使いながら改善します。ストア申請のような定型作業も手順化し、AIに任せています。
